# Сказка с тобой

Демонстрационный Telegram Mini App. Vue 3 / PrimeVue 4, FastAPI, PostgreSQL и отдельный worker. Это **частичная реализация** [архитектуры](docs/architecture.md), не готовая коммерческая система.

## Что работает

Проверка Telegram initData и часовая сессия, анкета, приватное нормализованное фото JPEG/PNG, фиксация анкеты при запуске, PostgreSQL-очередь, сборка PDF ровно на 10 страниц, список своих заказов, скачивание и отправка PDF по кнопке в Telegram, удаление заказа и файлов. Демо использует шаблонный текст и программные рисунки, не имитирует реальную оплату или персональные ИИ-иллюстрации. Фото не передаётся внешним ИИ.

## Запуск

Требуются Python 3.12, uv, Node 18+, Docker, шрифт DejaVu Sans.

1. Создать `.env` с `BOT_TOKEN=...`, `PUBLIC_URL=https://...`.
2. `uv sync --locked`
3. `npm --prefix frontend ci && npm --prefix frontend run build`
4. `docker compose up -d db` (PostgreSQL 18). Для локального демо с имеющимся образом 16: `docker compose -f compose.yaml -f compose.demo.yaml up -d db`.
5. `uv run python -c 'from app.core import Base,engine; Base.metadata.create_all(engine)'`
6. В отдельных процессах: `uv run uvicorn app.main:app --host 127.0.0.1 --port 8097`, `uv run python -m app.worker`, `uv run python -m app.bot`.
7. HTTPS-туннель на `127.0.0.1:8097`. Для ngrok нужен собственный authtoken. Временная альтернатива: `cloudflared tunnel --url http://127.0.0.1:8097`. Записать URL в `PUBLIC_URL` до старта бота.

Секреты, файлы пользователей, сборка и локальные процессы исключены из git. БД слушает только localhost; приведённые учётные данные предназначены исключительно для локального демо.

## Проверка

`uv run python -m pytest -q` — требуется запущенная БД. Проверки подписи/срока initData, доступа к чужому заказу, некорректной фотографии, повторного запуска, неизменяемости анкеты, 10 страниц PDF, кириллицы и удаления. Тестовый пользователь отдельный, созданные записи удаляются.

## Оставшийся объём архитектуры

Не реализованы реальные адаптеры ЮKassa и OpenAI, платёжные inbox/reconciliation/refunds, сущности Story/Page/Asset/AIRequest и финансовый аудит, бюджетирование, reference и QA иллюстраций, fencing/heartbeat/global slots, надёжный delivery outbox, админ-команды, автоматические сроки хранения, backup/restore/tombstone replay, rate limiting, Alembic и полноценный production Compose/Caddy. Тема и интересы сохраняются, но пока не меняют шаблон демокниги. Черновик сохраняется при изменении имени и перед загрузкой/запуском; полноценное автосохранение ещё нужно. Сроки 7/30 дней пока не обеспечиваются автоматически. Production mode намеренно запрещает запуск генерации, пока нет проверенной оплаты.

Публичный туннель временный, зависит от работающего компьютера и процесса. Не загружайте чувствительные фотографии в демонстрацию: для проверки подходит любая тестовая картинка. Коммерческий запуск требует закрытия перечисленных пунктов и проверки платёжного канала из архитектуры.

## Текущий демонстрационный запуск

Бот: https://t.me/fairytale_test1_bot . Временный адрес: https://bouzp-85-155-125-70.run.pinggy-free.link . Используется SSH-туннель localhost.run: ngrok token отсутствует, Cloudflare Tunnel получил TLS EOF. Процессы app, worker, bot и ssh-tunnel запущены локально; PID и журналы лежат в `.runtime/`. При остановке/перезагрузке машины пример перестанет работать. Туннель может сменить адрес; тогда обновите PUBLIC_URL и перезапустите bot. Проверен публичный health endpoint и настройка меню Telegram; ручная проверка Mini App в Telegram ещё необходима.

Для поддержания временного demo-туннеля: `.venv/bin/python scripts/demo_tunnel.py`. Процесс проверяет HTTP с браузерным User-Agent и содержимое страницы, при двух последовательных неудачах пересоздаёт localhost.run, обновляет PUBLIC_URL и перезапускает бота. Текущий адрес записывается в `.runtime/public-url`. Старые inline-кнопки Telegram не обновляются: `/start` выдаёт новую кнопку и обновляет меню чата. Этот механизм не обеспечивает постоянный домен или production SLA. Pinggy не используется: его промежуточная страница не подходит для этого Mini App.
